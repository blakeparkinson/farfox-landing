# Crewneck: switch to large-front embroidery (Printful dashboard)

Printful's API refuses large embroidery placements, so the Long Distance Club Crewneck (Printful product
478740784) was created with a 4×4in centre-chest crest. The dashboard allows the large front (up to
10×6in), which is the size the crest was designed for. About 5 minutes.

## Files (live on lovefarfox.com, 3000×1800 at 300 dpi, exact thread colours only)

| Colour | File | Threads |
|---|---|---|
| Oatmeal Heather | https://lovefarfox.com/shop/designs/apparel-2026-10/crew-large-oatmeal.png | lettering #6B5294 (purple), fox #CC3366 (flamingo) |
| Navy | https://lovefarfox.com/shop/designs/apparel-2026-10/crew-large-navy.png | lettering #FFFFFF (white), fox #CC3366 (flamingo) |

## Steps

1. Printful → Stores → your store → **Long Distance Club Crewneck** → **Edit**.
2. Pick the **Oatmeal Heather** variants. In the placements list, remove **Center chest**, add **Large front**,
   and upload `crew-large-oatmeal.png`. Set the thread colours above if Printful does not detect them.
3. Keep **Left wrist** (the pink heart) as it is.
4. Repeat for the **Navy** variants with `crew-large-navy.png`.
5. Save, and check the mockup shows the full LONG DISTANCE / fox / CLUB crest across the chest.

If the editor only allows one design for every colour, stop and say so: a single-design version (one thread
scheme that reads on both colours) is a quick change.

Large-front embroidery costs more than centre chest, so check the new cost in the editor against the $55 price.
After saving, tell Claude to refresh the crewneck shop photos.
