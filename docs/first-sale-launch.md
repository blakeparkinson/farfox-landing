# First-sale launch pack

The offer URL is:

`https://lovefarfox.com/personalized-long-distance-jersey`

Generate the three vertical videos with:

```sh
npm run launch:jerseys
```

They are written to `out/jersey-launch/`. Add a native trending sound in each platform's editor instead of baking copyrighted audio into the files.

## Posting sequence

1. Post one creative per day for three days.
2. Pin the best-performing post and keep its tracked link in the bio.
3. In Umami, compare `jersey_offer_view`, `jersey_personalized`, `jersey_add_to_cart`, and `jersey_purchase`.
4. If visitors personalize but do not add to cart, test price or shipping reassurance. If they add to cart but do not buy, inspect shipping cost and checkout abandonment before changing the product.

Use `utm_source=tiktok`, `instagram`, or `pinterest` to match the actual destination if a creative is cross-posted.
